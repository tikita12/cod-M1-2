# 목업의 실제 화면 반영

- 소개 배너와 상단 경로 영역 제거. 아이콘 목록과 오른쪽 채팅 패널 사용.
- 작은 화면에서는 채팅 패널을 목록 아래에 배치.
- 새 대화 `+`, 저장된 대화 `☰`, 닫기 `×` 버튼. Escape와 외부 클릭으로 닫기.
- 가격 상세·가격 편집 대화상자도 Escape와 배경 클릭으로 닫기.
- Firestore CRUD 및 대화 저장·조회·불러오기 경로 유지. 목업 localStorage 데이터와 혼합하지 않음.
- 실제 응답 저장 성공 시 Firestore 저장 완료를 안내. 실패 시 실제 오류를 표시.
- `/api/data/trend?item_name=배추`: 품종·등급·판매 수량·단위별 최근 관측 연도의 12개월 가격.
- 그래프는 실제 판매 수량에 대한 원 가격. 결측치는 연결하지 않음. 여러 해의 순위 통계와 별도 설명.
- 요약과 그래프가 동일한 서버 프로세스 캐시 사용. CRUD 후 둘 다 갱신.
- `scripts/build_preview_trends.py`로 정제 CSV에서 미리보기 그래프 생성. 2014-12~2024-12 범위 사용.

미리보기는 실제 CSV 분석 결과지만 현재 Firestore 조회 결과는 아니다. 미리보기에서는 CRUD와 AI 전송을 허용하지 않는다.
클라우드 할당량을 복구하는 변경은 아니다. 서버 재시작 후 최초 실제 분석은 Firestore를 다시 읽는다.

검증: 오프라인 API 및 분석 테스트, JavaScript 구문, HTML DOM 연결 확인.
실제 브라우저의 시각적 검증 및 OpenAI↔Firestore 전체 클라우드 연동 확인은 미완료.
